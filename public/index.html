The app automatically detects numeric feature columns in your CSV. No fixed sensor schema is required. Optional ground-truth column: label / is_anomaly / anomaly / target / class.
What happensPIPELINE

Automatic feature detection → preprocessing → baseline learning → Autoencoder-style reconstruction score + Isolation Forest-style outlier score + symbolic rules → confidence fusion → NORMAL / REVIEW / QUARANTINE → anomaly fingerprint → SEA state creation or reuse → recovery memory.

Your uploaded data becomes the input to the self-evolving pipeline. Similar future anomalies can reuse previously learned SEA states. Labels are optional and only used for evaluation when present.
